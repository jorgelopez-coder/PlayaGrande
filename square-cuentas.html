Cuentas Square

Registrá cada punto de venta que tenga su propia cuenta de Square (nombre, location ID y access token). El sistema descarga ventas por producto, pagos, descuentos y devoluciones de cada cuenta activa, en la frecuencia que elijas abajo, y las consolida en este mismo Sheet para análisis de ventas, revisión de inventario y control de operación.
